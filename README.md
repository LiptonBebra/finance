
  МОИ ФИНАНСЫ - программа для компьютера (Windows)
============================================================

ЗАПУСК - ВСЕГО ДВА ШАГА
------------------------

ШАГ 1. Распакуйте архив целиком.
   Правый клик по файлу MoiFinansy-PC.zip -> "Извлечь всё..."
   -> кнопка «Извлечь».

   ВАЖНО: не запускайте ничего из окна архива!
   Пока файлы не распакованы, программа работать не будет.

ШАГ 2. Откройте распакованную папку MoiFinansy и дважды
   щёлкните файл:

        MoiFinansy.exe

Готово. Откроется СОБСТВЕННОЕ окно программы - обычное окно
с иконкой, без адресной строки и панелей браузера. Окно можно
сворачивать, разворачивать и менять размер, как у любой программы.
При первом запуске на рабочем столе и в меню «Пуск» появятся
ярлыки «Мои финансы» - дальше запускайте ими.
ЗАКРЫТЬ ПРОГРАММУ - крестик окна (или кнопка «✕» внутри
приложения). Данные сохраняются автоматически.

НИЧЕГО УСТАНАВЛИВАТЬ НЕ НУЖНО
------------------------------
PHP (движок программы) уже внутри пакета, в папке php\.
Файл WebView2Loader.dll нужен для окна программы - держите его
рядом с MoiFinansy.exe (он уже в архиве).
База данных - файл data\finance.db внутри папки программы.
Ничего никуда не отправляется, интернет не требуется.
Права администратора не нужны.

ЕСЛИ WINDOWS ПОКАЖЕТ СИНЕЕ ОКНО
--------------------------------
«Система Windows защитила ваш компьютер» - это стандартная
проверка для программ без цифровой подписи (подпись стоит
денег, поэтому её здесь нет).
Нажмите «Подробнее» -> «Выполнить в любом случае».

ЕСЛИ ПРОГРАММА НЕ ОТКРЫЛАСЬ
----------------------------
1. Запустите Запустить.bat из той же папки - он покажет,
   что именно не так, и подскажет решение (текст на русском).

2. Если подсказка говорит про VCRUNTIME140.dll или Visual C++:
   установите компонент по ссылке
      https://aka.ms/vs/17/release/vc_redist.x64.exe
   и запустите программу снова.

3. Если антивирус заблокировал или удалил файлы программы -
   добавьте папку MoiFinansy в исключения антивируса и
   распакуйте архив заново.

ЧАСТЫЕ ВОПРОСЫ
---------------

В: Окно мигнуло и сразу закрылось.
О: Запуск был из окна архива. Распакуйте архив целиком
   (правый клик -> «Извлечь всё...») и запускайте
   MoiFinansy.exe из распакованной папки.

В: Ярлык не появился на рабочем столе.
О: Ярлыки создаются при первом успешном запуске
   MoiFinansy.exe. Если вы удалили ярлык, он появится снова
   при следующем запуске.

В: Пишет «Файлы программы не найдены рядом с MoiFinansy.exe».
О: Файл запущен из окна архива. Распакуйте весь архив
   («Извлечь всё...») и запускайте из получившейся папки.

В: Хочу, чтобы вход был без PIN.
О: На экране создания профиля нажмите «Продолжить без PIN-кода».

В: Программа открылась в браузере, а не своим окном.
О: В вашей Windows нет компонента «WebView2 Runtime» (он встроен
   в Windows 10/11, но может отсутствовать на старых системах).
   Установите его бесплатно по ссылке:
      https://go.microsoft.com/fwlink/p/?LinkId=2124703
   (файл MicrosoftEdgeWebview2Setup.exe, установка одна минута)
   и запустите MoiFinansy.exe снова - откроется обычное окно
   программы. Пока компонент не установлен, программа тоже
   работает - просто открывается окном браузера без панелей.

В: Как перенести данные на другой компьютер?
О: Скопируйте всю папку MoiFinansy целиком (или только файл
   data\finance.db при закрытой программе).

В: Как удалить программу?
О: Удалите папку MoiFinansy и ярлыки «Мои финансы»
   с рабочего стола и из меню «Пуск».
